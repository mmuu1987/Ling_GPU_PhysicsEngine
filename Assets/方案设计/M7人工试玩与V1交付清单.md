## 实际试玩（记录而非预填通过）

### 1. 首次上手：至少一位非开发者

- [ ] 未读内部开发文档，也能找到开始、暂停和返回入口。
- [ ] 从打开程序到首场轻量局完成，记录实际用时；目标五分钟内，不以自动战斗用时替代。
- [ ] 玩家能说明哪支军团获胜以及胜因；结算人数/损失可理解。
- [ ] 原样重开恢复完整兵力，能再次开战；返回布阵/目录没有卡住。

### 2. 山地与指挥

- [ ] 在山地绕行预设切换军团、下达移动/进攻/防守指令，鼠标落点和指示标记对应实际地面。
- [ ] 可看出上下坡和隘口路线，陡坡不可直接穿越；禁行/不可达命令有可理解反馈。
- [ ] 镜头移动、缩放不会影响基本操作；高低差交战、单位贴地没有阻断玩法的问题。
- [ ] 尝试调整布阵、保存新方案、离开后载入再开战；地形关联正确，原预设不被覆盖。

### 3. 据点、多军团与表现

- [ ] 中央据点的未占领、占领/争夺提示和最终胜因清楚；人工未遇到的分支如实记“未覆盖”。
- [ ] 三方混编可分别选择和指挥，终局统计包含全部参战军团；若人工加入第四军团，也能看懂其结果。
- [ ] 在远、中、近距离观察兵种和军团；确认能接受新远景减面的轮廓与动画变化，不能用近/中景像素一致替代远景人工观感。
- [ ] 实际听到开战、命令、据点与结束反馈，声音不过密/刺耳；音量/静音保存后重启有效。

已知非阻塞表现项：据点墙体默认材质紫色、部分初始视野被侧栏遮挡、远景辨识度以及更长时段内存趋势。试玩若发现它们确实妨碍理解或操作，再按实际影响升级，不因清单存在就自动判失败或自动接受。
