## 制作与隔离

`WarSandboxLaunchPresetsBuilder.Prepare` 只创建新目录，目录存在时拒绝覆盖。先生成全部配置和场景副本，再逐场景重新加载资源、配置入口和镜头，避免编辑器切场时使用已卸载的资源引用。

每个预设拥有自己的 Scenario、Unit、Spawn 和 Rules。24 个兵种模板拥有独立稳定 ID，复用既有战斗、移动和 VAT 资源。玩家方案仍使用既有格式和地形身份校验；应用时生成运行时副本，不回写预设。目录增加可选 description/briefing，旧目录继续使用原有说明。

`MassEngine/Launch Presets/Build M7.1 Windows` 构建菜单与五个场景，临时设置 Build Settings 并在结束后恢复。目录缩略图来自真实引擎的准备画面，使用 `ImportPreviewsAndBuild` 导入后构建。

## 自动验证

复用显式启用的 `WarSandboxTerrainCycle`：

```text
WarSandbox.exe -screen-fullscreen 0 -screen-width 1280 -screen-height 720
  --terrain-cycle --terrain-cycle-phase=presets
  --terrain-cycle-output=<新的绝对输出路径>
  --terrain-cycle-plans=<新的独立方案目录>
  -logFile <日志路径>
```

`presets` 保持产品自动进入轻量局的启动路径，依次调用真实 uGUI 控件完成四个预设的保存、修改、载入、应用、1 倍速自然结算、满兵重开和再战。另检查标准 100k 的开战/重开。返回目录后检查 GPU 与运行时副本释放、源资产内容和方案哈希不变。

`presets-ui` 检查最终缩略图、目标说明、五个入口和开战/重开/返回，并保存含 UI 的画面。截图时临时将 Overlay Canvas 交给离屏相机，结束后恢复。隐藏窗口显式提交完整 URP 渲染；本探针不提供桌面 FPS 结论。
