## 外观验证方法

新增入口：`MassEngine/Regression/M5.3 GPU VAT Appearance`。

`VatAppearanceRegression` 调用现役 `VatBaker`，只在唯一的 `Assets/VAT_Data/M53Verification_<GUID>/` 目录新建 Male profile；未使用会删除固定临时文件的旧 `--vat-rebake-keep` 路径。
`VatAppearanceRegressionCapture` 使用 `ResolvedUnitTypeRuntime` 实际解析的网格、材质和 MPB，配合 `AgentData`、可见索引和 indirect args，执行实际 ForwardLit/ForwardNoShadow pass；不是普通 MeshRenderer 的绑定姿态预览，也不是 CPU 解码后重建模型。

- 3 个版本 × 3 个 LOD × 4 个 clip = 36 组；每段取首帧、中间两帧、末帧，另查死亡末帧钳制。
- 每帧要求非空；每段至少有 4 个前景像素随动画变化；同时间重复绘制应无变化，避免相机/灯光噪声冒充动画。
- 捕获实际 shader 编译错误，以及几乎整片前景为 Unity 错误粉色的情况。
- 输出 153 张逐帧图、9 张分组图、3 张 Male 新旧并排图，以及像素统计、轮廓 IoU 和源依赖 SHA-256。
- 固定正交相机与光照、关闭场景雾和阴影、强制 LOD 后统一画幅查看。这覆盖 VAT 绘制路径，不代替场景光影、剔除分类或性能测试。
- far 死亡是强制检查 shader 的路径；实际分类通常不把死亡单位放入 far 桶。

现役 Male 为 Full 4112 / Low 994 顶点；重烘为 Full 4112 / Low 1004。已知 Low 拓扑差异来自 cleanMesh 的附件绑定姿态基准，不要求低模逐像素相等。
Female 的实际 Full/Mid/Low 为 **4066 / 2018 / 39** 顶点；Low 槽指向 `FemaleCharacterPBR_LowLOD_Mesh.asset`，不是额外的第四级 SuperLow。

### 首跑失败的分类

首跑 36 组全部有动画变化、死亡钳制无偏移、160 个源文件/元文件哈希不变，但夹具自身有两处问题：

1. 原先“超过 1% 粉色即报 shader 错误”的假设不成立。Female 已有 39 顶点低模的图集采样包含局部彩色色块，并非整模型错误 shader。改为检查真实编译错误和单材质绘制下 ≥90% 前景错误粉色，新增合法混色与阈值负控测试；没有修改贴图、材质或模型来迁就测试。
2. Direct3D 的 RT 投影与直接 ReadPixels 输出方向不一致，截图上下翻转。在读回时按 top-origin API 归一化一次，并补方向测试；没有旋转模型或改烘焙姿态。

首跑报告保留在 `Logs/M53Regression/appearance/`，复验另存 `appearance-final/`，不抹去失败证据。
既有低模放大后的彩色色块/轮廓粗糙，以及 Male 新旧部分动作和低模像素差异，保留图片供人工判断；不为远景资产观感开启本轮美术重做。

## 复现命令

从有效工作树运行；Unity 为 GUI 子系统程序，用 `Start-Process -PassThru -Wait` 取退出码，**不加 `-nographics`**。同一工程的 Unity 命令串行执行，性能采样期间不并行运行其他 GPU 测试。

```text
Unity.exe -batchmode -projectPath <工作树>
  -executeMethod MassEngine.Editor.VatAppearanceRegression.Run
  --vat-appearance-output=Logs/M53Regression/appearance
  -logFile Logs/M53Regression/appearance.log
```

从输出 `rebaked-male-path.txt` 取本次新建 profile 的精确路径；重复外观检查可追加 `--vat-appearance-rebaked-male=<路径>`，无需重烘。

```text
Unity.exe -batchmode -quit -projectPath <工作树>
  -executeMethod MassEngine.Game.Editor.WarSandboxVatRegressionBuilder.BuildWindows
  --vat-performance-profile=<上述 profile 路径>
  --vat-performance-build=Builds/M53Regression
  -logFile Logs/M53Regression/build.log

Builds/M53Regression/VatPerformance.exe --vat-performance
  --vat-performance-output=<绝对输出目录>
  -screen-fullscreen 0 -screen-width 1280 -screen-height 720
  -logFile <绝对日志路径>
```

这是专用验证构建，不是新增首发预设。正常游戏构建没有注入该组件，也不会自动启动性能测试。
保留日志/截图/CSV 后，只清理本次首次执行 `rebakedThisRun=true` 的 manifest 所指新建目录；不能因复用参数而删除调用方原有资产。
