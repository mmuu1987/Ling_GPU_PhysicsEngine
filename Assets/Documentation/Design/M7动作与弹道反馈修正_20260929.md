## 2. 已实施内容

### A. 停止与慢速移动

- 保留战术 Idle/Move/Engage/Attack/Dead 的含义，新增独立 `presentationState` 和 `locomotionSpeed`。
- 在位置积分、地形与边界约束之后，按最终三维位移判定 Idle/Move，不再用追击意图代替实际运动。
- 停止立即回 Idle；移动速度做轻量平滑，并用不同停下／启动阈值抑制反复切换。
- Move 倍率采用实际速度／兵种参考速度，并考虑 `scale.y`；不再在零速时继续播放 0.85 倍 Move。
- Idle/Move 各用自己的片段时长循环；Attack/Death 优先，尸体年龄不被表现切换覆盖。
- 两份 VAT shader 都读取新的表现状态，近景和远景规则一致。
- 仍使用现有四段素材，没有新增 Walk/Run；慢放 Move 不是新的 Walk 动作或完整足部锁定。

### B. 远程动作粗同步

- 远程沿用现有冷却缓冲，每帧轻量推进周期；第一次攻击增加准备阶段，在 `attackReleasePhase` 处累积发射请求。
- VAT Attack 相位由同一冷却映射，不再独立循环，也不被动画 LOD 重复推进。
- 保留异步回读、GPU 请求计数、CPU 弹道池和原有回读 generation 取消保护，不重构为全 GPU 生成。
- 持续周期按 `attackInterval`，首发时间有意后移；正常运行仍允许回读带来的少量帧延迟。
- 沿用引擎 `SafeDt()` 的单步 50ms 上限，避免严重掉帧时远程相对近战／移动加速。
- 修复暂停衔接：暂停保留目标、冷却、姿态与运动缓存，并冻结动画时间；继续不会重置周期或获得免费首箭。重置仍由 `ResetScenario` 负责。

### C. 高度、弧线与途中单位

- 平面／山地统一采用地表高度加兵种发射／瞄准高度；高度乘出生体型。无地形时保留出生脚底高度。
- 发射点前向偏移按身体半径和射向目标的方向近似，不新增整份 Agent 数据回读，不做逐帧骨骼枪口定位。
- 使用既有抛物线解法；位置积分改为 `v*dt + 0.5*g*dt²`，与发射解法一致。
- 现役三份远程模板统一使用较明显的抛射；直射 `gravity=0` 仍可用。
- 新增身体胶囊扫掠，通过现有空间格筛选候选，覆盖跨格弹道与较大身体。
- 单位和地形一起比较最早接触：**友军挡弹但不受伤；途中敌军可先于原目标受伤；排除发射者本人。**
- 已生成的在飞弹体不因原目标死亡／变阵而立即消失，继续飞行至命中、触地或到期；发射时的无效地形检查仍保留。
- 没有重新实现或替换既有地形导航、三维射程和地形扫掠；M73 远景资源未重新生成或改绑。

## 5. 尚未验证与明确限制

1. **没有运行十万人新性能基准。** 旧 M73 帧率结果不能代表新增碰撞后的版本，不据此宣称仍达到 30FPS。
2. 空间格桶溢出时，受影响的弹道会退回精确全表检查，避免无声漏碰；该异常路径昂贵。已有溢出遥测保留，正式规模仍需确认容量和帧时。
3. 身体是简单胶囊，不是骨骼／三角形碰撞；移动单位使用一帧位置快照；弹道每帧以弦段扫掠，大步长可能偏保守。
4. 体型支持是配置与出生 scale，不支持运行中任意动态缩放／飞行；本轮也未重做大型生物导航、近战接触或复杂身体部位。
5. 仍是粗同步：极端掉帧、回读延迟、弹道池溢出／消费上限时，不承诺逐箭对应每个动作。现有攻击素材也不会自动变成专用射箭动画。
6. 友军阻挡、首发前摇、弧线和弹体容差变化会影响对局，**没有声称战斗平衡完全不变**。
7. 尚需人工近景确认停止／慢移、准备／出手、前排遮挡和山地观感；小图绘制通过不等于真人试玩签收。
