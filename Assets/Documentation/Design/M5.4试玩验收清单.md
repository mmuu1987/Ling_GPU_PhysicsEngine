# M5.4 UnityChan 试玩验收

这是独立的模型制作管线试验，不替换默认 11 万单位场景。需要 Windows 和支持 Compute Shader 的显卡，不需要安装 Unity。
本文件是随构建复制的人工清单，不代表人工签收已完成。

## 启动

完整解压，双击 `Start-Trial.cmd`（1280×720 窗口），或运行 `ModelTrial.exe`。
不要只复制 exe；`ModelTrial_Data`、UnityPlayer.dll、MonoBleedingEdge 等同目录内容都必须保留。

## 请实际确认

1. **模型可见**：默认是 UnityChan 64 人，对内置士兵 64 人。用跟随/全景定位，滚轮拉近拉远，看完整模型和 LOD 切换。这里不复刻原 toon、脸部动画和头发物理，也没有新增武器。
2. **布阵**：进入“返回布阵”，选左侧 `UnityChan 试验兵`，把人数改为 96 并更新；模板下拉可切换后再切回。试验沿用原世界尺寸，预览脚印较小，推荐左侧数值编辑。
3. **保存**：打开“本地方案库”，填写两个不同字段：
   - **编号**：`M54_Manual`（只允许英文字母、数字、下划线、短横线）。若编号已存在，换一个新的英文编号，不覆盖旧方案。
   - **名称**：可填 `M54_人工验收`，这个显示名称支持中文。
   - 点击保存。不能把中文名称填进“编号”；旧版清单对此有误，本版已纠正。
4. **跨重启载入**：退出程序，重新打开，从方案库选取刚才的方案、加载并应用。正常试玩使用既有游戏方案库；自动检查的 Logs 隔离目录不会自动载入。
5. **开战**：保持 1×，按开始/Enter，观察待机、移动、攻击和倒地。之前 96 对 64 自动测试约 75 秒自然结算；不同部署/操作不保证相同结果。
6. **结算与重开**：看清胜者、胜因及存活/损失；点原样重开确认满兵且新模型仍在，再返回目录并进入。

请反馈这些项目通过，或提供具体步骤/截图。**自动检查通过不等于用户人工签收，也不是 V1 完成声明。**
