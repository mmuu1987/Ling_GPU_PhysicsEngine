# M7.2 全军团结算、反馈与设置

2026-09-27，实现与自动验证完成。对应 `GAME_DESIGN.md` 的 M7：所有实际参战军团结算、基础命令/战场音效，以及可保存的音量和静音设置。

## 试玩入口

运行 `Builds/M72Playability/Start-WarSandbox.cmd`，首次进入 512 人准备战场。Unity 仍使用 `Assets/Game/M71LaunchPresets/LaunchMenu.unity`。
菜单 `MassEngine/Launch Presets/Build M7.2 Windows` 重建此包，不覆盖 M7.1 的已验收证据目录。

- 战斗结束后显示胜者、胜因、时长，以及每个实际参战军团的名称、初始、存活和损失。
- “再来一局”恢复全部初始兵力并重新开战；“返回布阵”恢复战前方案；“选择其他战场”返回目录。
- 战斗中或暂停时可在指挥面板点击“结束本局（不判胜负）”。结果明确标记“手动结束 / 主动结束 · 不判定胜负”，不指定胜者。
- 底部和战场目录均有“设置”。音量滑块、静音、试听与恢复默认立即生效，点击“保存并返回”后跨程序重启保留。
- 打开设置会暂停正在进行的战斗，关闭后恢复。准备阶段和用户手动暂停的战斗不会因此自动开战；设置期间禁止发送战斗命令。

## 实现边界

既有 uGUI 已能动态列出多军团，本次补齐其冻结数据来源。`WarSandboxBattleResult` 保存独立军团行：军团 ID、名称、初始人数和存活人数；损失由两者相减。
只记录初始人数大于零的实际参战军团。行按值返回，遥测、重开、布阵与更改名称都不会改写已完成的结果；保留原攻守双方字段兼容旧调用方。
手动结束时使用最后一次有效异步遥测；若该军团尚无样本则保留初始人数，不编造伤亡。终局只处理一次。

`WarSandboxBattleFeedback` 订阅命令、开战、据点归属/争夺变化和结束事件；开战与据点变化同时显示短文字提示。
`WarSandboxAudio` 在整个进程中只使用一个常驻 2D AudioSource 和五个短音效，命令去抖、重要提示覆盖旧提示，不随士兵数量创建音源。
音效由本地正弦波包络合成，无外部音频素材。暂停/继续和每帧据点进度不会反复播放开战或占领音效。

设置文件为 `Application.persistentDataPath/WarSandboxSettings.json`，格式版本 1，默认音量 65%、未静音。
保存使用同目录临时文件和原子替换；损坏、不支持的版本或非法数值回退默认值并在界面提示，读取时不覆盖原文件。
保存失败保留当前窗口和错误提示，可重试或“返回（不保存）”。不写兵种、场景、默认方案或玩家配兵文件。
