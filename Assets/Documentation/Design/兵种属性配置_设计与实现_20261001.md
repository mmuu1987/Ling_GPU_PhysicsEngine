## 1. 目标与用户决策

玩家可以调整兵种的数值（生命、伤害、射程、速度等），而且**不改写官方兵种资源**。

| 决策 | 内容 |
|---|---|
| 方案 | 本局方案覆盖 + 方案内可"推送到全局"（用户选 B 方案） |
| 粒度 | 同一方案内，同一兵种（模板）共用一份覆盖，不能按军团分开设置 |
| 全局识别 | 按模板 ID（`templateId`）识别兵种 |
| 入口 | 布阵页"兵种属性"→ 兵种档案；目录页"兵种库" |
| UI 风格 | B"战术指挥"（深底、青 / 琥珀 / 紫） |

## 2. 三层数值模型

```
最终值 = 本局覆盖 ?? 全局覆盖 ?? 官方值      （逐字段判断，最后按范围 clamp）
```

- **官方（Official）**：读自兵种 `UnitTypeConfig` 资源，只读，永不回写 `.asset`。
- **全局（Global）**：保存在 `persistentDataPath/WarSandboxUnitOverrides.json`，所有战场、所有方案共享。
- **本局（Local）**：保存在布阵方案文件中，字段是可选的 `statOverrides`；为空时不写出，所以旧方案和旧版本都兼容。
- 没有覆盖文件时，游戏行为与旧版完全一致：运行时不克隆兵种，直接使用原 scenario。

### 可编辑字段（11 项）

| 字段 | 范围 | 说明 |
|---|---|---|
| 生命值 MaxHp | 1–100000（整数） | 只在配置里，不进 GPU settings |
| 攻击伤害 AttackDamage | 1–10000（整数） | |
| 攻击间隔 | 0.1–10 秒 | |
| 攻击距离 | 0.5–60 米 | |
| 索敌半径 | 0.5–120 米 | |
| 移动速度 | 0.1–20 米/秒 | |
| 冲锋倍率 | 1–5 | 仅近战 |
| 冲锋起速 | 0.1–1.5 | 仅近战 |
| 弹道射程 | 1–80 米 | 仅远程 |
| 弹速 | 1–100 | 仅远程 |
| 溅射半径 | 0–20 米 | 仅远程 |

`UnitTypeSettings`（GPU 侧）的 144B 已满，所以只开放已有字段，没有扩展核心结构。官方 30 个模板的数值都在上述范围内，有测试校验。

## 3. 代码结构

### 新文件（`Assets/Game/Scripts/`）
- `WarSandboxUnitStats.cs`：字段定义、范围、解析器 `WarSandboxStatResolver`，以及数据结构 `WarSandboxStatSet`、`WarSandboxStatOverrides`、`WarSandboxGlobalStats`。
- `WarSandboxUnitStatStore.cs`：全局文件的读写。
  - 写入流程：先备份 `.bak`，再写临时文件后原子替换，所以中途崩溃不会把文件写坏一半。
  - 文件超过 512KB 拒绝读取；JSON 损坏时把原文件改名为 `.broken-*` 隔离，游戏照常启动并给出提示。
  - `TryUndo` 可撤销上次全局修改。
  - 测试钩子 `DefaultPathOverride`，默认为 null。
- `WarSandboxDeploymentHUD.UnitStats.cs`：兵种档案面板（D1）和推送确认（D2）。
- `WarSandboxFrontEnd.UnitLibrary.cs`：兵种库（D3）。

### 修改的文件
- `WarSandboxDeploymentDraft.cs`：草稿中的本局数值，支持撤销（连续拖动合并为一步）；`Instance()` 生成 `"(Tuned)"` 克隆。
- `WarSandboxLocalPlanStore.cs`：方案文件增加可选的 `statOverrides`。
- `WarSandboxRuntimeDeployment.cs`：
  - 进入战场时应用全局覆盖（`TryApplyGlobalStatsOnLoad`）；
  - 应用布阵时生成运行时克隆兵种，并重建 GPU 参数；
  - `TryPushStats` 推送本局数值到全局，`TryUndoGlobalChange` 撤销；
  - 销毁时恢复原 scenario。
- `WarSandboxSceneSession.cs`：加载战场时注入全局覆盖，并给出 `StatsWarning`。
- `WarSandboxDeploymentHUD*.cs`、`WarSandboxCommandHUD.UGUI.cs`、`WarSandboxFrontEnd.cs`：入口、标记，以及"自定义数值"提示。
- `WarSandboxUGUI.cs`：新增 `LabelAligned`、`TintButton`、`TintField`、`TintSlider`、`TintScroll`，以及测试钩子 `ScreenSizeOverride`（默认 null，游戏不会设置）。

### 关键约束
- 加载期间 `BattleController` 处于输入锁定状态，`ResetBattleState` 会被静默跳过，所以加载时注入直接调用 `manager.ResetScenario()`。
- `UnitTypeRegistry.FillGpuSettings` 每帧从注册配置重建 GPU 参数，所以替换 scenario 后 GPU 会自动同步。

## 4. 界面

| 屏幕 | 入口 | 内容 |
|---|---|---|
| D1 兵种档案 | 布阵页 → 编成属性 →"兵种属性 / 自定义数值 ›" | 左侧是本方案的兵种列表和只读参数；右侧每个字段有滑块（竖线为官方值，对数刻度，范围为官方值 ×0.25–×4）、数值框、来源标签（本局青 / 全局紫 / 官方灰）、× 恢复按钮。底部按钮：恢复本兵种、撤销上次全局修改、推送到全局…、完成 |
| D2 推送确认 | D1"推送到全局…" | 列出"当前全局/官方 → 推送后"，可勾选"推送后清除本局中这些字段"（默认勾选） |
| D3 兵种库 | 目录页右上"兵种库" | 全部模板列表；可编辑全局数值，也可全部恢复官方、撤销、放弃修改、保存到全局 |
| 战斗 HUD | 顶栏 | 有覆盖时显示"· 自定义数值"（琥珀色） |

宽度不够时，档案和兵种库底部按钮自动排成两行。UI 缩放公式：`clamp(min(w/1280, h/720), 0.85, 1.5)`。

## 5. 行为细节（和设计稿的差异 / 限制）

1. 本局修改在"应用布阵"后生效，"保存方案"时写入方案文件。
2. 推送到全局或在兵种库保存后，**下次应用布阵或进入战场**才生效，不会热替换正在进行的战斗。
3. 战斗进行中只能查看，不能编辑。
4. 档案面板打开时会替换布阵主视图，点"完成"后才能应用布阵。
5. 远程兵种隐藏冲锋字段，近战兵种隐藏弹道字段。
6. 各战场里看起来相同的兵种，模板 ID 往往不同（例如骑士有 `roster-knight`、`cavalry-knight-control`、`dragons-phalanx-knight-90/150`），需要分别设置。兵种库**不显示**模板被哪些战场使用。
7. 出手时机、弹道高度、命中半径、拖尾长度属于资源参数，只读展示，不能编辑。

## 6. 测试与验证

| 项 | 结果 |
|---|---|
| EditMode `WarSandboxUnitStatsTests`（23 项：解析优先级、clamp、存储备份/损坏隔离/撤销、方案兼容、克隆不改写模板、推送等） | 23/23 |
| PlayMode `WarSandboxUnitStatsPlayModeTests`（官方菜单 → 进化巨龙方阵战场，端到端） | 通过 |
| EditMode 全量 | 458/460，失败的 2 项是既有的 EditorBuildSettings 问题（用户决定不处理） |
| EditMode `WarSandbox` 子集（最终代码） | 279/281，同上 2 项 |
| PlayMode 全量 | 151/158，失败的 7 项都在 `WarSandboxSceneEntryTests`，原因是旧场景 `Assets/Game/Scenes/WarSandbox*.unity` 不在构建列表中，改动前已存在（见 `Logs/AgentCharge/official-edit-01`） |

PlayMode 端到端测试验证了以下内容：
- 没有覆盖时运行原 scenario；
- 写入全局伤害 ×1.5 后重新进入战场，GPU 中巨龙的 `attackDamage` 为 135，骑士保持原值，模板资源没有被改写；
- 战斗能正常运行；
- 在档案中修改生命 ×2、移速 +1 并推送后，全局文件中有 4 项，本局被清空；
- 应用布阵后，GPU 和配置的数值都正确；
- 测试使用临时目录，不碰真实的 persistentDataPath。

已知覆盖缺口：`SceneEntryTests` 中涉及运行时布阵的 7 项因为构建列表问题跑不起来，目前这部分代码只靠新的端到端测试覆盖。修复构建列表后应重跑。

截图说明：批处理模式下编辑器的屏幕是 640×480，测试用 `ScreenSizeOverride` 按 1280×720 排版，再用相机渲染到 RenderTexture。这种方式拍不到 GPU 间接绘制的士兵（战场是空的蓝底），不代表游戏中的显示。

## 7. 手动验收建议

1. 打开官方菜单 → 兵种库，选"进化巨龙（超大）"，把攻击伤害改为 135，保存到全局。
2. 进入"进化巨龙方阵"战场，顶栏应显示"自定义数值"，开战后巨龙伤害明显提高。
3. 暂停 → 配兵与布阵 → 选巨龙 →"兵种属性"，把生命值改为 3000（来源变为"本局"）→ 推送到全局… → 确认推送 → 完成 → 应用布阵。
4. 回到兵种库，确认生命值为 3000（全局）；点"撤销上次全局修改"可以回退。
5. 删除 `%USERPROFILE%\AppData\LocalLow\<公司>\<产品>\WarSandboxUnitOverrides.json` 后，游戏恢复官方数值。
