# 来源与发行许可复核结论

2026-09-30｜当前包GUID `01c3512de1eb461c8923cbe7054ea84a`

**结论：两组资源的官方来源与游戏嵌入许可、字体作者许可、FBX及运行组件的许可依据现已定位。没有发现必须立即替换美术/字体或重写玩法的许可禁令。但原游戏ZIP缺少部分应附声明，且终端用户条款尚未落实，不能宣布“旧ZIP已具备完整正式发行手续”。**

用户本轮明确选择“本人/团队从官方取得”；按该真实陈述登记，不再列为来源完全未知。未查看或要求私人账号、订单、付款信息；此确认不等于审计了每个开发席位或Unity订阅资格。

## 2. DOS字体：找到了作者本人许可

不再以Fonts下载站的冲突标签作为判断依据。字体作者Zeh Fernando在自己网站、针对这款字体用于游戏的具体询问，明确回复“that font has a free license.. you can use it as you please”。[4](https://zehfernando.com/2012/ludum-dare-25-announced-theme-suggestions-now-open/)

据此可把“缺作者使用许可依据”改为“作者直接许可已定位，可作为当前游戏使用依据”。保留作者、原文和出处，见[作者许可记录](LicenseEvidence/PerfectDOSVGA437-Author-Permission.md)。这不是标准OFL/MIT全文，也不是一份对全球商标/字形权利的保证；不擅自改标为公有领域、MIT或OFL。当前字体不需要因为上一轮没找到文本就立即替换。

## 3. FBX：有分发许可，但要放对声明

实际随包Managed DLL有`Autodesk.Fbx.dll`、`Autodesk.Fbx.BuildTestAssets.dll`、`Unity.Formats.Fbx.Runtime.dll`。同时，当前309运行文件中**未见`libfbxsdk.dll`原生库**；不把存在C#绑定程序集说成完整原生SDK已全部入包，也不因为原生库未列出就删掉原本匹配包的声明。

[Unity承载的Autodesk FBX SDK 2020条款](https://unity.com/legal/autodesk-fbx)与随包文本对应：§1.1.1含商业开发；§1.1.3允许免费或收费产品分发，并要求“as is”；§1.1.4保留版权/专有通知；§1.1.5要求特定免责声明出现在终端许可/使用条款或About类页面，并出现在相关版权文档。不是“只能免费游戏”。不将长文中针对其他Autodesk软件的特殊not-for-profit条款无区别套用。

原文已在[版权声明候选](版权声明候选.md)。剩余是最终用户条款/通知的实际放置和随包，而非再问用户去购买另一份不明FBX许可。本轮未替用户接受协议、未更新游戏About或创建已生效EULA。

## 4. Unity Player、Mono、WinPix与D3D12

### Unity / Mono

实际UnityPlayer版本`6000.3.14f1 (d68c3f99a318)`。从[该版本官方发布页](https://unity.com/releases/editor/whats-new/6000.3.14f1)取得**Player / Windows / Mono / 6000.3.14f1**专属第三方声明，完整35页已归档为[官方PDF](LicenseEvidence/Unity-Player-Windows-Mono-6000.3.14f1.pdf)，不是取Editor声明或别的平台版本替代。

该表将Mono(Unity Fork)列为MIT，另含Boehm GC等各自声明。许可依赖不应只看15个PackageCache根文件；随发行保留这份完整Player声明及已有Package声明。在有效Unity授权/适用席位和档位前提下，[Unity Software Terms §2.2](https://unity.com/legal/editor-terms-of-service/software)允许Runtime嵌入项目分发，同时要求对终端用户的协议不低于其对Unity及许可方的保护。本轮不审计用户财务或订阅，不声称拥有无限制Unity分发权。

### WinPixEventRuntime

实际版本`1.0.240308001-release`，SHA与Microsoft NuGet **1.0.240308001**的`bin/x64/WinPixEventRuntime.dll`完全相同。这正是Microsoft公告指明的首个MIT NuGet版本，不把2024前旧版直接套新许可。[1](https://devblogs.microsoft.com/pix/open-sourcing-the-winpixeventruntime-under-mit/)

已归档该版本原始MIT全文与自带ThirdPartyNotices。保留版权/许可通知即可按MIT分发该组件；附带通知包含PIX产品范围信息，不据此声称那些依赖全都运行在本游戏里。

### D3D12：特别纠正“都是MIT”的误读

两份实际DLL的文件版本均为**1.618.1.0.20250923.2**，文件大小和SHA与Microsoft NuGet **1.618.1**的x64成员逐一完全相同：

| 文件 | SHA-256 |
|---|---|
| D3D12Core.dll | `625bd40005b1c3708695d5256ecf230d278e6b8edba5a88af70f3d91324f3052` |
| d3d12SDKLayers.dll | `c0730cc70d3250d3de19c04c17845ba9e70eecaf502d684d1409195ebc5b5959` |

虽然Unity的汇总PDF将Microsoft.Direct3D.D3D12条目写成MIT，**微软该版本包README明确：`LICENSE.txt`适用`build/native/bin/`；`LICENSE-CODE.txt`才适用`include/`头文件**。本项目分发的是前者二进制，以[微软二进制许可](https://www.nuget.org/packages/Microsoft.Direct3D.D3D12/1.618.1/License)为准，已原文归档，不用MIT取代。

其允许按条件随具有实质功能的Windows应用分发可分发代码；要求终端用户/分销者同意足够保护Microsoft的条款、保留通知、不暗示Microsoft背书等。**附上LICENSE是必要资料准备，但单独附文件不证明用户协议接受要求已经落实。** 不需要为此现在删除DLL或降成D3D11；是否裁剪属于另行新构建决定。

- NuGet元数据指向上游commit `f8a040b6ceede60530b9572e73a5cce5e867daba`，主许可MIT；自带第三方通知包括Oniguruma的BSD型二进制通知义务及其他MIT来源。已取该commit LICENSE和该版本NOTICE原文；不拿1.0.11的声明猜旧版。

已补入外置LicenseEvidence目录，同时保留Unity collab-proxy的UPDL引用和包级声明。**无需因“Editor来源”就推断无许可，但实际分发它时不能漏通知。** 如以后裁剪这一非玩法插件，需要新构建与必要烟测，本轮不直接删旧包文件。
