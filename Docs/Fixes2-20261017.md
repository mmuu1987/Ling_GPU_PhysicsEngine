## 补充：坦克火炮不能对空（同日追加）
问题：任何远程兵（射程 > 0）都可以把飞龙当目标，炮弹胶囊碰撞也会打中飞龙，所以炮车能打到空中的龙。

改法（改规则，不改架构）：
- `CombatConfig` 新增 `groundTargetsOnly`（默认 false），炮车设为 true（`CC0ArmsBuilder.ApplyValues`，已「只刷新数值」）。
- 选目标：`TargetIsUsable` 里，射手有这个标记时不选飞行单位。
- 弹道：这类射手的炮弹碰到飞行单位直接穿过（`ProjectileUnitCollision.hlsl`）。地面溅射本来就碰不到飞龙，不用改。
- 编码：没有加新 buffer。在原有的 `unitTypeFlight`（飞行高度）里，这类地面兵写 -1。`FlightAltitudeOf` 会把负数截成 0（还是地面），`AnyFlight` 只看 > 0。是个小技巧，记在 `UnitTypeRegistry.FillFlightAltitudes` 注释里。
- 机枪手和弓手仍然可以对空。炮车价格不变（价格公式不考虑对空能力）。
- 部署页只读摘要显示「只能打地面 · 不能对空」。


## 补充：机枪手削弱、坦克加血（同日追加，试玩反馈）
用户：「机枪手还是太强了，坦克一下子被秒了」。按用户给的数值改：
- 炮车血量翻倍：600 → 1200。
- 机枪手伤害减半（4 → 2），射击间隔翻倍（0.15 → 0.3 秒）。
- 机枪手改成一轮一轮打（用户选的方案）：每轮平均约 10 发，打完随机停 0–3 秒再打下一轮。
- 价格保持原价（用户选择）：机枪手 108、炮车 500。priceScale 3.25 → 6.5，0.594 → 0.4192（价格公式不计连射停顿）。

实现（新的可选开关，默认关，其他兵种行为不变）：
- `CombatConfig.burstShots`（每轮平均发数，0 = 连续）和 `burstPauseMax`（轮间最长停顿秒数）。
- 走现有的可选战斗变体（`MASS_MELEE_CHARGE`），新增每兵种一个 float2 buffer `unitTypeBurst`（SRV，不占 UAV）。
- `AdvanceRangedCycle`：每发之后以 1/burstShots 的概率结束本轮，加 0–burstPauseMax 的随机冷却。随机数由「单位编号 + 帧号」哈希得到，不需要额外的单位状态，所以每轮发数不固定，在 10 发上下浮动。
- 停顿时动画停在瞄准姿势，不会空放射击动作。
- 部署页只读摘要显示「连射 · 每轮约 10 发，之后随机停 0–3 秒」。


## 补充：点小地图编成徽章，镜头飞过去框住整个编成（同日追加，试玩反馈）
- 左键点编成徽章：照旧选中该编成，同时镜头飞到能看到这个编成全部活着单位的位置（站在编成后方、朝向最近的敌军，和「跟随军团」的取景方式一样）。

## 补充：大型单位半径减半（同日追加，用户决定「这些都减半，不用量」）
- 规则：`Assets/Game/Content` 下所有物理半径 ≥ 2.75 米的兵种，半径 ×0.5；近战/远程的 attackRange 同步减去同样的量，让「身体外的攻击距离」不变（下限 半径 + 0.6）。
- 主要数值：巨兽暴龙 11.7 → 5.85（攻击距离 14.85 → 9）；红龙 8 → 4；绿龙 7.5 → 3.75；黑龙、蓝龙 6.5 → 3.25；剑龙 4.5 → 2.25；蜘蛛 4.8 → 2.4；三角龙、大狼 3.6 → 1.8；大牛 4 → 2；巨人 3.2–4.2 → 1.6–2.1；旧龙 3.4–4.3 → 1.7–2.15；骑士 3.3 → 1.65（攻击距离 4.35 → 2.7）。
- 炮车 2.8 → **1.55**（不是 1.4）：半径 ≤ 1.5 米会离开大型单位通道（`IsLargeBody`，网格 3 米），并把所有普通兵的导航留宽撑大到 1.4 米。
- 生成器同步：`KaijuBuilder`（半径减半，攻击距离减同样的量）、`FourDragonsBuilder`（4 / 3.75 / 3.25 / 3.25）、`CC0ArmsBuilder`（炮车 1.55），以后重新烘焙/刷新数值不会改回去。
- 影响：骑士冲阵每次撞到的人会变少；巨兽和龙同时被围攻的人数变少，会更耐打（价格公式不算半径）。旧方案照样有效（半径变小只会更宽松）。
- 一次性脚本已归档到 `outputs/Rad/archive/`（不提交）。执行时菜单被触发了两次，巨兽和四龙被减成 1/4，已按日志改回「减一次」的值并逐项核对。
