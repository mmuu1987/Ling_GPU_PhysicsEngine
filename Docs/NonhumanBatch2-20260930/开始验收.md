# 统一角色库 · 非人形第二批

双击Start-Roster.cmd，默认三角龙场。点布阵/编辑→兵种，可在同一大型菜单选巨狼、公牛、三角龙、剑龙、蜘蛛、适配骑士。切换使用安全默认人数和阵型，保留军团/位置，检查后应用。

大型仍限攻方，守方用适配骑士；不是任意密集混战。默认2对16，先保持小规模。本批保守圆/中心距离，不是甲壳或腿部精准碰撞。

底部战场目录可直接切三个新场景，或回旧12常规自由编成/全角色示例/原大型入口。向下滚动看后续卡片。手动目录继续UnifiedRosterPlans，旧场景身份保留，没有自动迁移/改写旧方案；自动测试用隔离目录。

蜘蛛现在使用新LargeSpider04，同一2.5mm门禁通过；不要用旧失败Spider02/03。
