# 第二批怪物 / 六种敌方目录

双击Start-Enemies.cmd，默认兽人场景。底部“战场目录”可选雪怪、蘑菇怪，以及上一批斧盾/双刃/持杖骷髅；向下滚动查看后几项。

拉近/旋转镜头看体型、四动作、武器和LOD；雪怪更高大，另两种有原生持物。新3种复用近战，没有新技能/发光效果；外观更圆润，材质按原图集和工程光照呈现。

可改人数、保存、退出后重载、自然结算、重开和返回；胜负不是本轮平衡结论。手动EnemyModelBatch2Plans独立于旧方案目录，CMD设置在本包PilotData，不自动迁移旧方案。

工程制作仍从MassEngine > Character pipeline > Open workflow选择Orc、Yeti、MushroomKing配方，生成换新编号。不要重跑历史准备器/覆盖产物。

完整说明PilotReport/第二批怪物结果.html和README.md。没有旧代码/核心改动或100k/提交推送/法律/V1放行。
