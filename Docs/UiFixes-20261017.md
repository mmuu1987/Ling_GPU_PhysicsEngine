# 试玩反馈修复（2026-10-17）

| 问题 | 原因 | 改法 |
|---|---|---|
| 战场目录底部的按键提示（↑↓ / ENTER / 双击）文字溢出底框 | 系统中文字体的行高比测量值高，按键框没有固定高度 | `.key` 固定高 22px，文字居中（`WarSandboxUi.Toy.uss`） |
| 战场目录页没有方案入口 | — | 顶栏新增「方案库」：选方案后自动进入方案所属的战场并载入（`WarSandboxFrontEnd.Plans.cs`，调用 `WarSandboxDeploymentHUD.TryEnterPlanBattlefield`） |
| 加载进度条一直是 0% | 读取场景以后，场景激活加上战场初始化在主线程上一帧跑完（实测约 8 秒 + 6 秒），进度条和界面都无法刷新 | 改成分阶段显示：读取资源 0–60%；激活前先把「构建地形与军团（画面会停顿几秒）」画出两帧，再开始激活。要让进度条全程真实走动，需要把战场初始化拆到多帧，这一项没做 |
| 布阵页右上角单独一行系统按钮（帮助/设置/战场目录/退出）占掉屏幕顶端 | — | 这几个按钮并入「编成 → 布阵 → 开战」顶栏；总览页隐藏浮动按钮条，页面上移（`Deploy.uxml/.uss`，`DeployHudOwnsSystemMenu`） |
| 正式包里有「十万人压力试验」 | — | 只在 Editor 和 Development Build 里显示（`Debug.isDebugBuild`） |
| 巨兽移动太慢 | maxSpeed 7（男战士 12），之前全局速度 ×2 时巨兽漏改 | maxSpeed 14（资产 + `KaijuBuilder`）。单价按公式自动上调约 13%（≈8782 → ≈9900） |
| 结算画面小地图一直闪 | 小地图每帧被显示，又在 0.12 秒一次的刷新里被结算逻辑隐藏 | 结算时不再显示小地图（`WarSandboxCommandHUD.Toolkit.cs`） |
