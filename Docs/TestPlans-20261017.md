# 测试方案库 + 跨地图载入（2026-10-17）

## 跨地图载入（修 bug）
- 以前：在 A 地图载入 B 地图的方案会报错「请先进入此方案所属战场」。
- 现在以方案为准。确认框会提示「此方案属于地图「XX」：将切换到该地图并自动载入方案」。确认后切换地图，新场景就绪后自动进入布阵并载入方案。
- 不会强行载入的情况：地图已不存在，或地图的版本、地形有变化。这两种情况直接提示原因，不切换。
- 方案列表里显示中文地图名；不在当前地图的方案会标注「（载入时切换地图）」。
- 代码：`WarSandboxDeploymentHUD.Plans.cs`。切换前记下待载入的方案；新场景的 HUD 在 `Update` 里接着载入（`ResumePendingPlan`）。确认框文字由 `PlanLoadNote()` 提供（uGUI / Toolkit / 旧版 IMGUI 三处共用）。

## 测试方案生成器
- 菜单 `Tools/测试方案/生成测试方案（自动进 Play，写入方案库）`：
  - 走游戏本身的流程：进战场、布阵、校验，再用 TrySavePlan 保存。地图和兵种的版本号一定与当前目录一致。
  - 结果写到 `persistentDataPath/WarSandboxPlans`，并复制一份到仓库的 `TestPlans/`。
- 地图：用固定种子 20261017 从 5 张 2048 地图里随机抽。阵型放不下时，按顺序改用其他 2048 地图。
- 布阵：先按地图原有出生点排兵，放不下再试居中、不同间距和偏移；最后的兜底是把部队拆成小块逐块放置。
- 可选：在 `Logs/TestPlans/only.txt` 里写方案编号（逗号分隔），只重建这几个。
- 菜单 `Tools/测试方案/安装到方案库`：把 `TestPlans/*.json` 复制到方案库，不用进 Play。
- 日志：`Logs/TestPlans/status.txt`。
