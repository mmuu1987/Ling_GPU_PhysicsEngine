## 空间与出生重叠
每方5万：0.4密度时约238×524米，Z超出地图；0.7时约180.187×396.412米，能合法放在现有512地图的两侧。
不能只调密度：默认出生点抖动为步长8%，会让部分点对低于1.1米直径。使用实际DefaultSpawnModule生成十万人检查时，原8%抖动产生21607个重叠点对。
因此新增SpawnConfig.formationJitterFraction（默认仍0.08），DefaultSpawnModule读取该参数；**只有17版复制出来的模板改为0.02**。旧模板默认值0.08通过审计，旧源资产哈希未变。没有缩小人物、减小0.55碰撞半径或关闭物理。
- Editor十万人：全部位置通过地形可行走检查；重叠点对0；最小水平间距1.149904米，保守间距下界1.149716米。
- EXE十万人：应用/开战同一帧、首次后续模拟Update前读取GPU agent buffer；全量十万个初始位置按1.1米直径检查，重叠点对0、最小间距1.149904米。此结论只针对初始占地，不宣称之后运动/交战全过程零接触或所有模型肢体不相交。
