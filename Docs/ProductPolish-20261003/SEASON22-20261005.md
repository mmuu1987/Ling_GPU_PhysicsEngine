# 22版：林间三季试玩包

## 用户方向与交付
用户认可21版树林的基调，并选择“同类布局，不同季节氛围”。本版保持21版树林布局，提供三张可在同一战场目录选择的独立场景，不做三次覆盖式更新。

- 夏日绿林：`woodland-summer22`，清绿树冠、原有林下小景。
- 金色秋林：`woodland-autumn22`，金黄与铜橙植被、暖色地表和远景。
- 薄雪冬林：`woodland-winter22`，霜色树冠、斑驳薄雪和显露土路；隐藏203个花/蘑菇物件，不删除源资源。

启动 `Builds/WoodlandSeasons-20261005-22/Start-Terrain.cmd`，1920×1080独占全屏。首页进入战场目录后选择季节，再进入布阵。

GUID `a2f900ed189d4391aeac27a59b1739de`；Win64 Development，0error/20warnings。源目录 `Assets/Game/Season22`，菜单及Summer/Autumn/Winter四个场景实际入包。19、20、21包保留；未commit/push。

## 范围与实现
共用512地图、实际战斗地面与外围背景网格、导航、布阵空间、角色大小/碰撞半径和认可的角色预览。季节只改变景观，没有新增天气伤害、移动惩罚、碰撞障碍或新玩法。

复制景观材质与需要季节调色的颜色纹理，保留源21及更早资产；不改角色颜色纹理/VAT。地表沿用世界空间法线与林下蒙版，添加秋季混色、冬季薄雪覆盖；保留道路辨识度。远山与雾色跟随季节。冬季没有强行把所有树石刷成纯白，也没有动态落雪粒子或雪地脚印。

每张场景保留2045个装饰renderer、331633装饰三角面；冬季203个花菇inactive，active renderer为1842，其余两季2045。这是场景资源统计，不是当前可见draw call统计。每季景观材质23；夏季引用景观纹理21张，秋冬各23张。普通纹理上限512，主草地1024，菜单缩略图512。原始高精度素材未被覆盖。
