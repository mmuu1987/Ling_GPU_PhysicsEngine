# Ranger02 持弓游侠试点

双击本包Start-Ranger.cmd，默认64游侠对64私有慢速近战对照，限帧设置30FPS。请使用CMD隔离设置到本包PilotData；人工方案在RangerPilotPlans，不复用旧骑士/流程方案目录。内部EXE沿用通用构建器的KnightPilot.exe名称，但数据是本包Ranger02。

1. 拉近看待机、跑动，身体/弓/颜色是否正确。
2. 开战看搭箭、拉弦、松弦和真实飞行弹道。只承诺大致配合，不是骨骼发射或逐帧同步。
3. 看倒地和近中LOD；细弦和脸部细节在Low可能简化，是否接受待你确认。
4. 可部署96v64、保存、退出再开重载、自然结算、重开满编、返回。游侠被近战击败不代表失败：本轮不是兵种配平。

制作请从Unity的MassEngine > Character pipeline > Open workflow选Ranger02.asset，重复生成用新名字。Ranger.asset/01仅为挂接诊断历史。

详见PilotReport/游侠试点结果.html和README.md。旧04及旧包不覆盖；无100k、提交推送或法律/V1放行。
