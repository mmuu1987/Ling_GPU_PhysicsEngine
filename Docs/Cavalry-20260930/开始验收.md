# 剑盾骑兵第一套 · 正式02入口

双击Start-Roster.cmd，默认2骑兵对16适配骑士；点布阵/编辑可改人数、保存、重载。战场目录保留以前所有统一角色入口，骑兵场与巨兽场的接敌配置分开。

请拉近看坐姿、随马运动、挥砍与整体倒地，尤其骨盆/鞍位、双腿/马侧、脚蹬和缰绳。卡通比例第一版，不是写实骑术。

这套由现有CC0骑士与CC0马派生制作，不是原厂骑乘动作，也不是把站立人形放马背。统一VAT作为一个单位；没有上下马、落马、冲锋伤害或击飞。

正式配方MountedKnight01，场景Assets/Game/Cavalry/Prepared01/Integrated02/Menu.unity。构建01是上下文诊断，不是最终入口。

手动继续UnifiedRosterPlans，设置包内PilotData；无自动迁移/改写。报告PilotReport/骑兵接入结果.html。旧包保留，无100k/提交推送/法律V1放行。
