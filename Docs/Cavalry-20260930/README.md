## 不是把站立人形放马背

本轮明确是**派生制作的骑乘动画**，不是取得原作者完整成套骑兵动画，也不是骑马物理模拟：
- 马使用作者Idle、Gallop、Attack_Headbutt、Death；骑手上身使用已有Idle、Melee_1H_Attack_Chop、Death。
- 以马背Torso骨骼建立鞍位坐标。骑手骨盆跟随该坐标，双腿使用两节骨骼约束形成坐姿；移动时附加轻微上身随动。
- 马和骑手按同一四动作时间轴采样，攻击与倒地同时推进。骑手与马**作为一个单位整体倒地**，不做落马、尸体分离、上下马、冲锋伤害或击飞。
- 本轮新增简易鞍垫/鞍座/脚蹬，缰绳两端跟随马头和持盾手的骨骼，统一进入同一VAT。
- 目标为卡通比例第一版：马完整高度约1.8m，骑手原站立比例约1.95m，组合整体高度约3.02m。不是写实骑术/影视动作。

数值检查：骨盆至鞍位目标最大约0.00013mm，脚部骨骼至脚蹬目标约0.00025mm，膝角109.3°–126.5°，确实不是直腿站姿。**这些是骨骼目标约束，不是臀部/靴底网格表面零穿插证明**；接触和比例仍需人看。

## 几何与预算

原始静态缩放在自有Mesh/bindposes中规范化，原Knight/马/动画文件不改；共享图集左半Knight、右半马与新鞍具颜色，使用8×4色块划分。不是把马的无UV材质硬套到旧骑士图集。

Full10872、Low2106≤2200，145帧@24FPS（Idle80、Move15、Attack26、Death24）。骑乘约束实时采样姿态与序列化动画重放共1576440顶点帧核对，最大约0.000763mm≤0.25mm；VAT独立LBS参考最大约1.087mm≤2.5mm。48GPU动作/LOD结果+16独立位置参考，共用shader/UV/法线，非原材质独立验收。

两套骨架/装备合成后位置+法线纹理约36.250MiB，配方显式48MiB预算；不是单体旧32MiB或总显存承诺。未经大量骑兵性能测试，30FPS只是功能限帧设置。
