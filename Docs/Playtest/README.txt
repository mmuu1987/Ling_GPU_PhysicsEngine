战争沙盒 · Windows 试玩

将整个压缩包解压到一个可写文件夹，双击 Start-WarSandbox.cmd。
游戏会进入一场512人的准备战场。可以先按界面提示自行探索；需要帮助时再看“操作说明.txt”。

第一次试玩请记下从启动到首局结束的大致用时，以及你理解的胜者和胜因。
结束后填写“试玩记录.md”，记录没看懂的地方或无法继续的步骤。“未尝试”也可以照实填写。

可继续体验山地绕行、中央据点与三方混编，切换入口在底部战场目录。
设置和自己的布阵方案保存在本机；测试保存时使用新的方案名，避免覆盖原有方案。
每次由启动脚本运行，会在 Feedback 文件夹生成一份新的日志。遇到问题时可连同记录交给项目维护者。

本包是供实际玩家体验的候选版本，人工体验尚待确认。
版本与已知问题见“版本与已知问题.txt”。
