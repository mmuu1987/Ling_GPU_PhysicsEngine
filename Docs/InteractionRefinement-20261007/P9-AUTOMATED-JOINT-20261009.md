## 5. 过程中发生的问题与处置

- 上次复制中断：Collections 包源码超过 Windows 普通路径长度，改用仅此次复制的扩展路径补齐；不修改全局设置、不重建已复制项目。
- 新夹具曾把 Grid 当成 Runtime 读取诊断计数，只修正测试侧 API。
- 固定帧数不足以跨过 UI 的 100ms 刷新周期，改为同时等待真实时间；不修改产品 UI。
- Unity Test Runner 默认 180 秒单测期限短于预先约定的 420 秒自然战斗观察期限，明确设为 900 秒框架期限；**自然结算的 420 秒截止、正常时间与断言均未放宽**。
- Test Runner 即使指定结果路径，仍会写用户目录的 `TestResults.xml`。检测到后暂停后续，从历史验证目录找到 SHA-256 完全一致的原副本并恢复。运行器随后逐次备份，只在确认内容等于本次结果、且无其他编辑器/游戏进程时恢复。玩家方案和设置没有改变。
- 早期失败与最终通过分开保留；没有用生产代码修改掩盖夹具问题。
