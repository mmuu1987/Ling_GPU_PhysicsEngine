## 四、性能基线：有效数据与废弃数据分开

先前三个 batch Editor 采样只有 640×480，缺少有效 GPU 帧时和渲染帧计数，**不采用为正常游戏性能结论**。原始数据保留，另有 `batch-performance-not-qualified.json` 明确标注。

有效补测条件：

- Unity 6000.3.14f1；实际设备 **NVIDIA GTX 1060 3GB / Direct3D11**。
- Green 默认开战流程，2,048 人；**实际渲染 1920×1080**，不是仅指定启动参数。
- 游戏相机实际渲染回调计数；同一初始镜头，三次位置一致，单次首尾位置／朝向一致性检查通过。这里没有录制完整逐帧相机轨迹。
- 预热 10 秒，采集开战第 10～30 秒；vSync=0，targetFrameRate=-1。
- 不启用功能诊断的全军同步 GPU 读回；CPU 使用 ProfilerRecorder，GPU 有效计时来自 **FrameTimingManager**。

| 次数 | 渲染样本／有效 GPU 样本 | CPU 主线程中位／P95 ms | GPU 中位／P95 ms | 平均 GC 分配 KiB/样本 |
|---|---:|---:|---:|---:|
| 1 | 2,683 / 2,682 | 5.144 / 7.608 | 5.136 / 5.953 | 37.85 |
| 2 | 2,693 / 2,693 | 5.126 / 7.103 | 5.118 / 5.976 | 37.96 |
| 3 | 2,696 / 2,696 | 5.104 / 7.299 | 5.094 / 5.988 | 37.73 |

解释边界：

1. 这是 **Editor 下同条件的技术比较基线**，不是 EXE 的 FPS 保证，也不是独占全屏验收。
2. 不覆盖长局、峰值近战、近距离大模型、高人数或所有地图／模式；不能把它当性能上限。
3. CPU/GPU 的最新可用计时可能滞后，未把缺失 GPU 样本当成 0 ms。
4. 包含 Editor 和采样器自身开销；GC 也不是零分配。
5. `graphicsDriverAllocatedAfter` 是图形驱动分配估计，不冒充显卡实际驻留显存。
6. 可选的 Profiler 反射接口探测失败，未用其数据作结论；后续运行已停用该备选开关。有效 GPU 数据是 FrameTimingManager 的正值样本。

证据：`P0/rendered-performance-01/`～`03/` 下的 JSON 与逐帧 CSV。
