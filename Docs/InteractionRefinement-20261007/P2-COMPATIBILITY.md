# P2 半径字段与生效边界兼容说明

日期：2026-10-07。范围仅为半径编辑、保存、预览和实际应用；拥挤诊断属于 P3。

## 1. 数据契约

- 新枚举 `AgentRadius` 追加在索引 **11**；原有 0–10 不改位。
- 稳定字段键为 `agentRadius`，单位为米，写入已有 `stats` / `statOverrides` 数值数组。`schemaVersion`、`valuesVersion` 仍为 1。
- 全局按 **templateId** 匹配，不按模型名称、模型网格或外观合并。相同模型的不同模板不自动同步。
- 优先级：**方案局部 > 全局 > 官方**。恢复某一局部字段意味着重新跟随全局；它不等于强制恢复官方。
- 旧文件没有此字段时使用官方值，不批量重写旧方案。非法、非有限、越界字段在反序列化时计入跳过项并沿用现有读取警告；其原始文件不会因读取而被改写。界面输入直接拒绝，不偷偷夹到边界。
- 数字输入采用浮点往返格式，保存、重新读取不会因显示两位小数而丢失半径精度。

## 2. 两层限制，不把“可保存”误当“任意场景可用”

### 存储范围：0.05–4.8 米

下限避免与现有障碍／弹道消费者的 0.05 米最小值继续分歧；上限覆盖 P1 追踪到的当前官方配置最大值。该范围是这一版明确支持的编辑范围，**不是物理引擎对任意半径的普遍保证**。

当前只开放已能追踪到默认生成／半径链、且有显式 FlockingConfig 的模板。自定义模块或没有可编辑群体配置的模板不伪装为已支持。

### 当前战场准入

当存在有效半径修改时，还必须同时满足：

1. `2 × 最大有效半径 ≤ cellSize`，不扩大既有固定邻域查询，不自动修改网格。
2. 依实际 DefaultSpawn 行列数、占地与抖动上界，检查相邻生成点能够容纳对应直径。
3. 编成占地向外扩展相应半径后，不越出战场留白、不与其他编成扩展矩形重叠。
4. 使用候选半径重新进行地形导航／部署校验，不借旧的运行中清距蒙混过关。

矩形包络和抖动上界是保守检查，可能拒绝某些实际上恰好不碰撞的排列；错误信息会说明需要降低密度、扩大占地、移动编成或减小半径。**不会自动减少人数、缩小模型、改伤害、改军团或调网格。**

准入失败时保留原部署，整份候选配置不作部分提交；若同次还修改了攻击等数值，也不能把其中一部分误当成已经应用。

无有效半径修改、且未启用过本局半径清距覆盖时，保持旧部署路径，不借 P2 全面重判历史编成。

## 3. 哪一步会生效

| 操作 | 预览 | 保存文件 | 当前战斗 GPU |
|---|---|---|---|
| 图鉴输入／滑块修改 | 立即显示待编辑值 | 不写入 | 不改变 |
| 放弃修改 | 恢复已保存全局／官方 | 不写入 | 不改变 |
| 明确保存全局 | 显示已保存值 | 按模板 ID 原子保存 | 不热更新 |
| 新进入战场 | 使用有效覆盖 | 不自动重写 | 准入通过后克隆并上传 |
| 明确应用布阵 | 显示局部 > 全局 > 官方 | 不自动保存全局 | 准入通过后重建部署 |
| 战中保存新全局值 | 图鉴可显示新值 | 更新全局文件 | 保留已应用值 |
| 普通重置／再战 | 基于当前已应用部署 | 不读写所有方案 | 保留当前已应用半径 |
| 清除局部覆盖后应用 | 跟随全局／官方 | 不自动改全局文件 | 更新为新的有效值 |
| 清除全局覆盖后重新入场 | 官方值；有局部覆盖仍优先 | 清除动作须明确保存 | 新入场校验后使用有效值 |

运行时只克隆需要改动的 FlockingConfig，同模板多个编成共用一份本次部署拥有的克隆。未发生有效半径变化时仍引用原配置。克隆随部署释放，源 `.asset` 不写入。

## 4. 为什么单独处理地形清距

旧路径保留历史较大清距；仅在重置前把数值清零，会被尚未释放的旧注册表再次抬高。

P2 采用显式部署边界：先完成候选准入检查，再暂停并释放旧 GPU／注册表，设置本次部署的最大有效清距，随后初始化新部署。失败按原场景／清距回滚。候选 CPU 校验使用同一候选值，避免缓存沿用旧半径。

- 调大后恢复官方并明确应用：清距可以回落，不被旧高水位锁住。
- 普通重置：保留已经接受的本局值，不偷偷读入后来保存的全局数值。
- 重新加载场景：由新的运行实例重新解析全局覆盖。
- 从未使用半径覆盖的旧路径：原高水位规则不改变。
- 导航清距仍保留原有 **0.45 米安全下限**，而且使用全体有效模板的最大值；它并不是每名士兵各自的导航半径。

此变更不是接触分离、战斗拥挤或导航策略的全面修复。

## 5. 圆环的含义

深金色圈沿用 P1：表示当前预览值对应的 **1× 接触半径**，计入预览主体的 XZ 缩放。模型本身没有因编辑半径而缩放。它不是攻击范围，也不是保证不可穿透的硬碰撞墙。

图鉴圈展示待编辑／已保存的全局预览值；方案侧栏展示局部 > 全局 > 官方的有效值及来源。有局部覆盖时，修改图鉴全局数值不会自动覆盖该局部值。

## 6. 保存与回退

继续使用现有临时文件、刷新、备份、Replace／Move 写入机制；失败不替换主文件，取消不落盘。没有自动迁移全部旧存档。

**不能只把源码退到旧版，然后用旧版重新保存新数据。** 旧读取器会忽略不认识的 `agentRadius`；再次保存可能丢弃该字段。

需要回退时：

1. 先退出正在使用该工程／保存目录的程序，不强退用户进程。
2. 完整复制当前全局文件、`.bak` 和方案目录到带时间戳的独立备份；尤其保留包含 `agentRadius` 的原始文件，不只备份解析后的对象。
3. 核对并记录备份哈希，再按 P2 逐文件备份与变更清单受控还原源码。不使用 reset/stash 掩盖其他改动。
4. 旧版／37 只能使用确认过的独立旧格式保存副本；不要让它覆盖 P2 原件。保留原件供恢复 P2 后读取。
5. 本轮没有执行回退、没有修改真实用户数据，也没有自动启动 37 或制作 38。

隔离样本随 P2 证据交付，仅用于核对格式与测试，不自动复制到用户默认保存目录。
