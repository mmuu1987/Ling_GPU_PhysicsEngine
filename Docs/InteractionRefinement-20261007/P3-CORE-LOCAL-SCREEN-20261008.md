- 已有均匀方向表激活且宽度≥3时，用next-cell的索引差还原相邻dx/dz，省去重复除法/取模；宽度1/2有歧义或非均匀中心时保持原算式。
- 以上组合；没有新缓存/数组，没有组合上轮回读候选。
每模式3次预热、12次轮换测量，含当前生产、冻结基准及三个原型。冻结基准/生产每输入差异均在预设±3%内；候选必须六份均比冻结基准快至少10%才继续，结果均不满足。
