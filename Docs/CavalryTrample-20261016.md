# 骑兵冲阵（乙）：践踏穿阵 + 冲锋护甲（2026-10-16）

## 规则（PR #53，默认关，只有剑盾骑士开）
- `CombatConfig` 4 个字段：`trampleDamageMultiplier`（践踏倍率，0 = 关）、`trampleSpeedLoss`（每撞一人减速）、`trampleMinSpeedFraction`（践踏起速）、`trampleDamageTaken`（冲阵承伤，默认 1）。
- 速度 ≥ 起速 × 最大速度时进入冲阵：穿过小体型敌人，每人只打一次，伤害 = 攻击 × 倍率；每撞一人掉一点速度；撞到大体型（巨兽级）就停下；被撞的人被推开。
- 冲阵中受到的伤害 × 承伤；冲阵中不停下来原地打（`trampleRiding`）。
- 剑盾骑士：倍率 2、减速 0.25%、起速 0.45 × 移速、承伤 0.15；原有冲锋 ×3（0.6 × 移速）不变。
- 实测（TestPlain2048，40 骑冲 3000 男战士）：开 590–793 杀，关 39–40 杀；冲进 15–20 米，约 20–24 秒全部阵亡。

## 面板（2026-10-16）
- 兵种属性面板新增「冲阵 · 践踏」组，4 项可调：践踏倍率 0–5 ×攻击、每撞一人减速 0–5 %、践踏起速 0.1–1.5 ×移速、冲阵承伤 0–1 ×。只对近战显示。
- 枚举只追加（`WarSandboxUnitStat` 第 12–15 项），旧存档的键不变。

## 定价（2026-10-16）
- 系数 ×(1 + 1.0 × 倍率) × (1 + 2.8 × (1 − 承伤))；剑盾骑士 = 3 × 3.38 ≈ ×10.1（原草稿 ×2.0）。通过属性解析器读，玩家改了数值价格跟着变。

## 已知问题：骑兵波浪式一阵一阵浮动（未修）
- 现象（用户反馈）：骑兵特别明显，看起来像波浪一样上下 / 前后浮动，一阵一阵的。
- 步兵也有类似情况，但比骑兵轻很多（用户观察）。
- **已验证（2026-10-16）：和流场更新有关。** 临时工具 `WaveProbe`（已归档）在 test-plain-2048 上放 200 骑对 2000 男战士，记录接敌前每一帧 41 个骑兵的朝向 / 速度：
  - 骑兵的前进方向带一个约 **1.1 Hz 的左右摆动**（每 0.9 秒摆一次），幅度约 ±1.2°（模型朝向跟着摆，相关 0.94）。15 米内的邻居摆得几乎同步（相关 0.65–0.78），40 米外互不相关 —— 一片一片约 30 米宽的马群各自一起摆，看起来就是波浪。
  - 只改流场更新间隔（`RuntimeFlowConfig.dynamicFlowUpdateInterval`，默认 0.35 秒）：

| 设置 | 摆动频率 | 摆动幅度（°） |
|---|---|---|
| 0.35 秒（默认，两次） | 1.12 Hz，很明显 | 1.19 / 1.19 |
| 0.1 秒 | 1.88 Hz | 0.56（减半） |
| 1.0 秒 | 没有明显摆动 | 0.53 |
| 0.35 秒 + 松散队形（面积 ×2.5） | 1.12 Hz | 0.82 |
| 0.35 秒 + GPU 流场每帧 8 遍（原 2 遍） | 1.88 Hz | 1.40 |
| 关 GPU 流场导航（回退 CPU 流场） | 不成片，单兵乱抖 | 4.41 |

  - 结论：摆动随流场更新间隔变化，不是马挤马（队形放松仍在），也不是 GPU 流场收敛慢（8 遍仍在）。速度的忽快忽慢很小（约 2%），和流场间隔无关；奔跑动画相位是随机的（不同步），排除动画。
  - 步兵也摆，但幅度约一半（0.64°），而且人小，所以看着轻。
- 可能的修法（未做，待定）：① 只改画面：大体型单位的模型朝向做平滑；② 单位采样流场方向时做时间平滑（新旧方向几帧内过渡）；③ 查动态目标（密度扇区中心）为什么每次更新来回跳。把间隔改成 1 秒能消掉摆动，但对敌人移动的反应变慢。
