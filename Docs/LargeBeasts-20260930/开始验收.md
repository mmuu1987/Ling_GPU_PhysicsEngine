# 大型兽形：本轮正式两种

双击Start-Beasts.cmd，默认巨狼。底部战场目录切公牛和此前六种敌方，滚轮下翻看后续。默认8大型对32骑士，请先保持小场景；当前不是大数性能证明。

1. 拉近/旋转看真实四足、六米级体长、角/尾/脚底和四动作。
2. 下移动命令看转向，再开战看停下攻击及双方扣血。采用保守圆占地与软分离，不是长条胶囊/精确牙齿命中或零穿插保证。
3. 可改12大型保存，退出后重载，重开满编、返回。手动LargeBeastPlans独立于旧目录，设置包内PilotData。

蜘蛛攻击帧没有过2.5mm门禁，正式目录明确不含蜘蛛。Wolf02、Bull02为最终配方；其他本轮准备/配方属历史诊断，不要混用。

报告PilotReport/大型兽形结果.html及README.md。没有新增技能/核心重构、100k、提交推送或法律/V1放行。
