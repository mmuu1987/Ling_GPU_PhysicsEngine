# KayKit 剑盾骑士：独立小场景试点

**这是内部试点，不替换你之前验收的游戏包，也不是十万人性能测试。** 默认64骑士对64内置士兵，功能预览限30FPS。模型/动画：KayKit by Kay Lousberg，CC0；完整游戏中的其他资产仍沿用各自条款。

## 启动
关闭本试点后再启动其他测试，避免并发。双击 `Start-Knight.cmd`（窗口1280×720），（推荐用此CMD隔离设置；直接运行 `KnightPilot.exe` 会沿用默认设置路径）。自动进入独立战场，未开始时可以配兵。正式旧包和旧存档没有搬走/覆盖。

人工试玩方案使用独立 `KnightPilotPlans` 目录；CMD设置使用本包 `PilotData/settings.json`。自动测试另用 Logs 下的隔离目录，不写个人方案。

## 建议你检查这些
1. 骑士身体比例、脚落地、朝向是否自然；盔甲/披风/面罩颜色正确；剑和盾是否在对应手中、没有悬浮。
2. 不启动时看Idle；启动后看Move，交战看真实单手斩击，阵亡看Death。近中远缩放查看模型连续存在，Low LOD简化是否可接受。
3. 配兵把骑士64改为96、对手仍64，应用并保存方案；退出此程序再开，读取该方案并确认数量/骑士模板没有变回旧模型。
4. 点击开始，等自然结算；点击重开，确认满编回来且能再开始；返回菜单，重新进入同一试点。
5. 操作采用既有UI/镜头方案；不用任何自动化命令参数进行人工检查。

## 验收边界
- 自动测试调用真实UI回调，不代表物理鼠标键盘已由人验收。
- 独立GPU检查强制每个LOD、每种动作进行绘制；它不是镜头运动中的LOD分类器/视觉质量的人工结论。
- 已完成的阶段与数值见同目录最终报告；若尚无最终报告，不把这份清单当成通过证据。
- 卡顿、粉色/破面、武器明显错位、动作冻结、角色消失、保存失败或不能返回应反馈；轻微动作时序不是逐帧命中合同。
- 30FPS是节约测试负载的上限，不是此角色的十万人能力证明。正式候选原有29.43/29.70FPS记录不受影响。
