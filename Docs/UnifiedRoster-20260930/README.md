## 不是只注册Catalog

原RuntimeDeployment只从初始Scenario提取Templates，所以Catalog中有名字不代表能从布阵选择。本轮新增可选WarSandboxRosterPolicy：
- **仅新场景启用**明确角色清单，初始Scenario只有2种也能提供12种真实可选模板。
- 角色切换/新增采用安全模板默认，不再在该预览中默默新增1000人；切换会重设人数/密度/手动尺寸，军团与位置不动，支持撤销/取消。
- 复用原校验，再校验本场角色许可、半径与网格、物理占地密度、预览人数上限；不安全候选不写GPU/源/已应用方案。
- policy为空时保留旧Scenario-only列表、旧1000新增默认和原校验行为，旧斧盾对照实测通过。

修改只在游戏层RuntimeDeployment、DeploymentDraft、DeploymentHUD与其UGUI展示，新增policy/准备器/只读验收辅助；**没有改战斗、寻敌、分离、渲染内核或公共VAT烘焙器**。

普通角色私有配置使用小规模默认6、稀疏密度0.12、搜敌/远程上限12m以适合3m私有网格；这是整合预览，不改旧角色原值，也不是兵种配平结论。大型场沿用9m私有网格、占地和中心距离适配，限制大兽攻方/骑士对照，未验证大兽互斗。选择后若脚印相交或越界，要先调整位置再应用。

## 老骷髅补齐了什么

原Sazen素材实际有Idle、Run、Slash01、Death，但原主战场未收录完整四槽。仅复制6份现有FBX到新导入目录，旧FBX/meta/Prefab/PSD/材质不动。

新Prepared/Atlas/FourClips/Full/Low/私有Unit：Full11987、Low2499≤2500、112帧@24FPS。原姿态按固定参考根与实际变换采样核对1342544顶点帧，最大约0.01077mm≤0.25mm；VAT最大约1.400mm≤2.5mm。48GPU动作/LOD结果+16独立位置参考。共享shader/UV/法线，不冒充独立原材质验收。

原右手Falchion的挂点变换直接读取原Prefab；两张原贴图重新打成私有图集，绿色眼部发光色固化进albedo，**不等于原发光/Bloom效果**。使用StandardClustering，未把普通纹理强套4×4色块规则。原材质/骨架不改。

中途直接复制原曲线的准备版本未通过姿态对照，第二版仍约84mm差；改为实采原动作局部变换后通过，没有降容差。旧版本保留。第三次执行已完成骷髅/角色库，随后新场景的Deployment组件在运行时才由Bootstrap创建，直接取组件失败；后续仅在新场景调用既有EnsureControls补齐接线，没有重烘焙成功骨骼或改旧场景。所有失败回执保留。
