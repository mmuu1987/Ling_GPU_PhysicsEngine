# 新旧统一角色库

双击Start-Roster.cmd，进入自由编成。点“布阵/编辑”→选编成→“兵种”下拉菜单，可选12种常规模型；滚轮看后续选项。切换采用安全默认人数/阵型，保留军团与中心，检查脚印后应用。支持新增不同角色同场、保存与重载。

底部“战场目录”可选“全角色示例”，直接看12类新旧角色同场；大型适配场只有巨狼、公牛、适配骑士，大兽限攻方，不是14种任意无条件混战。

手动方案UnifiedRosterPlans，设置包内PilotData，不自动迁移旧方案。常规最多256、大型64，仅为此预览安全边界。

游戏内与随包有UnityChan的UCL署名/原文；原资产商店角色并非CC0。旧包保留，非全局玩法/性能/法律V1签收。详见PilotReport/统一角色库结果.html与README。
