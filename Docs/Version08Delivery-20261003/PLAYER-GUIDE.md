# 玩家指南 · Version08

适用 GUID：`eea0c353522542919393aa8b05eaaea0`。Windows Development 候选；无需安装 Unity 编辑器。不要只复制 EXE，须保留整个运行目录。

## 开始一局

1. 在 `Builds/Version08-Synced-20261003-01` 双击 `Start-WarSandbox.cmd`，以 1280×720 窗口启动。普通启动不附加测试参数。
2. 默认“开阔对冲 · 快速上手”是 512 人准备战场。按 **Enter** 开战，**Space** 暂停/继续，也可点击界面按钮。
3. 准备阶段可进入布阵，选择军团、编成和兵种，调整人数、位置及阵型；先处理越界、拥挤、禁行等校验提示，再应用。
4. 自然结算后查看胜者、胜因、各军团初始/存活/损失人数。原样重开恢复当前应用方案的完整兵力；这不是战斗中途存档。手动结束不判胜者。
5. 从“战场目录”返回选择其他战场；离开前留意未保存修改提示。

## 镜头与命令

- 鼠标在战场区时，右键配合 WASD 移动镜头，滚轮缩放；按 F 聚焦/跟随所选军团，F3 查看全景。
- 右侧选择军团，或用数字 1–9 按军团列表位置选择。A 进攻，H 防守，R 撤退；M 后左键点地面下达移动，Esc 取消待选落点。
- 输入框编辑、布阵界面或设置面板占用输入时，先结束输入/关闭面板；右键镜头导航期间不触发 A/M/H/R 指挥快捷键。
- 山地使用真实高低差与通行限制；不可达落点不能靠反复点击强行穿越，按界面提示改选路线。

当前有 29 个可选战场、66 个可选模板；含复用模型的不同配置，**不是 66 种独立身体模型**。旧 31/68 个战场/模板身份保留兼容。绿皮小怪、骷髅头不再提供新的正式选择，不等于从旧方案或包内删除其身份/资源。机器人默认 64 对 64，已有自动验证的 96 对 64 是专用保存方案，不是默认配置。

兵种可用范围及人数限制依战场不同；兵种库有条目不等于每场可任意混编。机器人使用中性脸四动作 VAT，不宣称完整表情系统、飞行或特殊技能。

## 保存、载入与设置

准备阶段从方案库另存，例如 `V08_Manual_01`；重要方案先备份，不覆盖原槽位。需要显式确认的覆盖/载入，核对提示后再操作。保存的是战前规则与部署，不是实时血量/进度；默认工程预设不作为玩家方案覆盖。

普通启动使用 Unity `Application.persistentDataPath` 下 `WarSandboxPlans/` 和 `WarSandboxSettings.json`。当前 ProjectSettings 的公司/产品名已核对，普通路径为：`%USERPROFILE%\AppData\LocalLow\DefaultCompany\Ling_GPU_PhysicsEngine`；若未来改公司/产品名，应同步更新此路径。当前 CMD **没有**给玩家存档设置包内隔离目录；更换候选包不要假定个人数据互不影响。

设置里调整音量/静音。设置面板会暂停正在进行的交战，关闭后恢复之前状态；手动暂停不应被解除。设置读取失败时有默认值与错误提示，不要为“修复”而删除所有玩家方案。
