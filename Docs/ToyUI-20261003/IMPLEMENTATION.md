## 本轮实现
- 普通启动进入主菜单；目录采用左分类、中卡片、右简介，选定战场后自动进入布阵，而非直接开战。
- 布阵采用左军团摘要、中央部署图；空间编辑器按选择展开，可收起，窄小编成也可通过军团卡片的“布阵”按钮选择。
- 独立军团详情页管理现有编成的兵种、人数、军团归属、近战/远程组成与属性；并未增加新的子编成数据层级。
- 角色预览取自工程 Catalog.unitPreview；关键数值取自 DraftStats 的有效值。没有生成角色替换，也没有混合军团平均攻击或虚构战力。
- 详情完成只提交到本局草稿；返回不自动应用、不保存方案、不启动战斗，镜头与草稿继续保留。
- 更换兵种、兵种详细属性、方案库按需打开；保留现有校验、撤销/重做、方案与数值覆盖逻辑。
- 战斗 HUD 顶部简要战况、底部军团与命令，更多工具/帮助/统计按需显示；有效结算报告替换命令层。
- 共享 uGUI 改为奶油浅底、天蓝栏、暖橙主按钮和运行时缓存的圆角九宫格；不引入外部 UI 素材依赖。
