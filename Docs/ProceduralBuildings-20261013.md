## 结论
在本项目的风格（Q版、纯顶点色、平面着色低多边形、俯视 RTS 视角）下，程序化建筑能做到与已完成的自然类道具（树、石、花草）同一水准。
难度比自然类高一档，但难点不在单栋房子，而在两点：
1. **组合**：一群建筑要像村子、像城，需要布局规则；
2. **玩法**：建筑挡路时会影响寻路 / 流场与部署区。

## 各类建筑效果预估
| 类型 | 效果 | 说明 | 预计轮数 |
|---|---|---|---|
| 农舍、木屋、谷仓、帐篷、栅栏、拒马、水井 | 好 | 墙体 + 坡屋顶 + 门窗色块，全参数化，变体多 | 1 |
| 中式古建（歇山 / 庑殿顶、飞檐、院墙、牌坊） | 较好 | 屋顶曲线与翘角可参数化；斗拱、雕花需简化为色块 | 1–2 |
| 西式中世纪（木筋墙、石屋、塔楼、教堂） | 较好 | 结构规整，比中式容易 | 1–2 |
| 城墙、城门、角楼、城堡 | 好 | 模块化（墙段、垛口、角楼）沿路径自动布置，是程序化最擅长的 | 2–3 |
| 村落 / 城镇布局 | 中等 | 沿道路分地块、朝向道路、留空地，需要调规则 | 1–2 |
| 现代建筑（楼房、住宅、工厂） | 易做，风格受限 | 方盒子 + 窗格阵列，效果像「玩具城」；玻璃反光、招牌、管线等细节在纯顶点色下表现有限 | 1 |
| 地标（宫殿、宝塔、大教堂） | 不推荐 | 独一无二的造型，程序化性价比低，建议以后手工 / AI 模型做 | — |

程序化不擅长：独特细节与叙事感、室内、损毁状态（可做简化版：塌顶、断墙）。

## 与玩法的关系（开工前需要定）
1. **装饰还是障碍**
   - 只放战场外围当背景：不影响玩法，最简单；
   - 放进战场挡路、可卡位：建筑要写进禁行格，寻路 / 流场随之改变，部署区（左右各 255×561 m）必须避开。
2. **性能**：单栋约 200–800 三角形，数百栋没有问题；长城墙段数量多，需要按段合并。
3. **主题**：现代建筑与冷兵器战场是否搭配，由用户决定。
