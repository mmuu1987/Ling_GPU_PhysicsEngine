# 三种敌方模型 · 开始验收

双击Start-Enemies.cmd。默认斧盾骷髅，底部“战场目录”切换双刃骷髅和持杖骷髅；持杖卡片需向下滚动目录。每场64新模型对64骑士，三种是不同身体/服装模型，不是换色。

1. 拉近/旋转镜头看脸、骨架、原头饰/披风、武器。法杖某些侧面可能被帽子遮挡；最终用Mage03。
2. 看待机、移动、攻击、倒地以及近中LOD。持杖沿用现有抛物线弹道，不含新火球/召唤特效。
3. 各场可改变人数、保存、退出再开重载、自然结算、重开、返回。胜负不等于接入失败，本轮不是兵种平衡。

手动方案EnemyModelPlans，与旧骑士/游侠目录分开；不同场景有独立身份，不自动跨场景迁移。CMD设置在本包PilotData。

Unity制作入口仍为MassEngine > Character pipeline > Open workflow，选SkeletonWarrior、SkeletonRogue、SkeletonMage03配方；再生成换新编号。不要重跑历史PrepareAll或覆盖已有产物。

报告PilotReport/敌方模型结果.html，详细说明README.md。旧包保留；无100k、提交推送、法律或V1放行。
