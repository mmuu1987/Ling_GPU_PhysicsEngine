3. 处理 glTF 蒙皮节点坐标规则，避免把手节点 scale=100 再叠加一次。以独立矩阵/权重/形变计算对照每个采样顶点，不以外观猜测代替精度门槛。
4. 源手部权重并非 L1 和为 1，最高约 1.755。按原来源 Three.js r160 `GLTFLoader` / `SkinnedMesh.normalizeSkinWeights()` 的行为规范化导入权重；原始权重数据没有被改写。没有放宽通用权重检查。
5. 当前有效准备目录 `.../Version01/Prepared04`：仅派生件做单位尺度 Generic 适配，将刚性动画部件转换为单骨蒙皮，保留原手部蒙皮。保留真实位置动画轨道，没有复制网页运行时“删除所有 position 轨道”的处理。
6. 所选四动画的面部权重键逐一证明为零（Idle 81、Walking 24、Punch 21、Death 24 个键）。因此四状态准备派生件使用中性脸；原始全部表情数据保留。这不是完整面部表情 VAT 支持。
