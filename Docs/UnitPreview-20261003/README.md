## 本轮范围

用户要求兵种图鉴与独立军团详情的大图改为实时3D预览，并封装成其他页面可复用的小功能。左侧列表小头像保持静态；不更改战斗、军团草稿、兵种数值、Catalog身份、模型/VAT资源或GPU内核。

## 复用入口

```csharp
ui.ModelPreview("unique-id", rect, exactUnitConfig, staticFallbackTexture);
```

- `UnitModelPreviewRenderer`：独立渲染服务，可脱离当前页面使用；实际游戏的 `ResolvedUnitTypeRuntime` Full-LOD网格、材质副本、VAT参数和待机片段。拥有一个RenderTexture、三个单单位GPU buffer及CommandBuffer，无战斗模拟器、实体角色或场景Camera对象。
- `UnitModelPreviewWidget`：RawImage控件；处理左键拖动、滚轮、复位、切换和隐藏/销毁生命周期。播放使用unscaled时间，不受战斗暂停影响。
- `WarSandboxUGUI.ModelPreview`：当前UI的薄接入层，提供交互说明与复位按钮；其他页面只传区域、配置和静态回退图。
- 已接入图鉴右侧、查看模型弹窗、军团详情大图。窄窗口无图鉴侧栏时使用“查看模型”弹窗。军团详情传实际 `e.template`，不按去重代表替换旧编成身份。

## 渲染和取景

以独立视图/投影矩阵执行真实VAT forward pass到RenderTexture；不调用场景Camera.Render，不把预览对象放到战场。统一灯光/无雾无阴影只作用于该次CommandBuffer，随后恢复矩阵、全局光照参数、关键字与输出目标。

历史mesh包围盒有的涵盖死亡/行走范围，有的只有参考姿态，不适合直接作为预览取景依据。每个VAT profile首次使用时读取实际待机片段顶点范围并缓存Bounds，后续复用缓存；这个初始化GPU读回有明确像素预算，不在每帧发生。不能取得范围时使用原包围盒保守回退。

按全部水平角和允许俯仰范围的固定待机包络适配控件纵横比，旋转不再重新改变缩放，给身体/武器留白；旋转俯仰有限幅，缩放0.6–1.8，复位还原默认朝向与取景。最长边768像素，保持比例，渲染更新最多30次/秒；不是整款游戏限帧或性能承诺。

页面不再使用节点、整个UI隐藏或控件销毁时释放目标纹理、buffer、命令缓冲与材质副本。再次显示时惰性创建。无可用VAT/GPU路径时显示静态回退及提示；没有静态图时显示缺失说明。
