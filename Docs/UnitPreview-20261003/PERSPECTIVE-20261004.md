# 角色预览透视、俯视与阴影加深（2026-10-04）

用户试玩06反馈阴影太淡、默认视角过平，并进一步明确要求从正交改为透视。已授权实施。本轮仅改共用预览，不更改战场相机、角色资源、蓝灰底板或已认可的拖动方向。

## 当前实现

- 使用真正的`Matrix4x4.Perspective`投影，垂直FOV固定30°。仍是独立CommandBuffer视图，不创建场景Camera对象，也不调用战场Camera。
- 默认俯视角从12°改为28°，水平角仍-28°；复位恢复28°、默认水平角和距离。交互俯仰限幅仍-20°至45°。
- 默认距离根据真实待机Bounds、控件aspect、所有yaw/允许pitch包络计算，额外预留模型深度半径。不用当前旋转角重新适配距离，连续转动期间FOV与距离不变。
- 滚轮只改变距离倍率（0.6–1.8），不改变FOV；最近距离不得进入模型待机包围球与近裁切面安全区。控件比例变化/切换角色时重新适配。普通近大远小、转身轮廓宽窄变化属于真实透视，不承诺所有角度屏幕轮廓大小一致。
- `ViewHalfHeight`现在仅为目标中心平面的视域半高诊断值，不是正交size；新增CameraDistance/ProjectionMatrix诊断供定向测试。
- 假阴影中心alpha由0.28提高到0.45，颜色和平方柔边不变。更高默认俯视同时让地面阴影更易看见。仍无实时阴影，不随待机跳动，不改变取景计算。
