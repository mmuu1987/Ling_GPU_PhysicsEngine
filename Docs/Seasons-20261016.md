# 2048 地图：季节切换 + 城堡放大（2026-10-16）

## 季节切换（方案 B：同一张地图开战前选季节）
- 选地图页底部「季节」：绿地 / 秋天 / 雪地 / 荒漠（按钮尺寸固定）。默认亮地图原来的季节；换地图自动回到原样。UI Toolkit 和旧版 uGUI 都有。
- 原样：丘陵会战 = 绿地，山脊隘口 = 秋天，断崖高原 = 雪地，峡谷台地 = 荒漠（`BattlefieldSeasons.NativeByMapId`）。
- 只改画面：地形、禁行区、战斗规则、保存的布阵方案都不变。
- 换什么：地面贴图（道具库 `ProcProps/Ground/<主题>`）、雾色、景物模型（同位置 / 同高度 / 同朝向，按类别换成该季节的同序号变体；雪地去掉花草蘑菇），房子按调色板换（绿 / 干 / 雪顶，原地换，不改大小）。
- 实现：`BattlefieldSeasonSwitcher`（场景里，Awake 时换，然后运行时静态合批）；编辑器工具 `BattlefieldSeasonsSetup` 把它装进场景，并去掉景物的静态合批标记（否则模型换不了）。
- 菜单：`Tools/战场 2048/季节切换/装到全部 4 张 2048 地图`。生成 2048 地图（`Battlefield2048Menus.Run`）后会自动再装一次。
- 地图场景在 .gitignore 里只存本地：别的机器上要先生成地图（或跑上面的菜单）。

## 城堡放大（方案 A，约 2 倍）
- 要塞：外墙边长 56 → 约 110 m；城墙、门楼、四角塔、主堡整体 ×2（`Decorator.PlaceAt` 新增 scale / tall 参数）；每面墙中间加 2 座塔（×1.6）；主堡（平顶带垛口，24×24 m、约 28 m 高）正中加一座尖顶高塔（×2.2，纵向再 ×1.6，顶约 60 m）。帐篷、木箱、营地按 2 倍范围摆，数量 ×2。
- 地点半径 46 → 92 m；没有地方放得下时退回原尺寸（日志 `Logs/Battlefield2048/<地图>-towns.txt`）。
- 4 张 2048 地图已重新生成，4 座要塞都是 2 倍（各 35 栋建筑），放置 0 失败。
- 仍然只是装饰，不挡路，不影响战斗。

## 已知
- 原样是雪地的断崖高原全是松树，切到秋天时枫树很少（松树还是松树）。
- 荒漠季节下原有的松树保留，所以比峡谷台地原样绿一些。
