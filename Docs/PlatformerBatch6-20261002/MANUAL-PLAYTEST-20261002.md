## 3. 菜单和三种新模型

每场至少看一次准备状态、移动、攻击和单位死亡：

- [ ] 目录能找到三张新卡片，中文名称与预览正确；鼠标点击能进入对应战场。
- [ ] 进入后能看到正确角色，不是粉色错误材质、空模型、明显错位或完全不播放动作。
- [ ] 待机、移动、攻击、死亡动作可辨认；若有明显抖动、漂移、巨大伸缩或严重穿插，记录截图和触发动作。
- [ ] 按 **Enter** 或界面开战按钮实际开战；**Space** 暂停 / 继续可用。
- [ ] 相机及部队操作按屏幕提示执行；UI 点击不会误变成战场指挥操作。
- [ ] 三场分别自然打到结算，界面不一直停在“进行中”，无崩溃或持续错误提示。
- [ ] 结算后重开 / 重置，兵力恢复到本次应用过的完整配置，而不是沿用战后的伤亡人数。
- [ ] 返回目录，再进入其他一场，角色、兵力和 UI 不串场。

## 4. 保存方案 → 完全退出 → 重启载入

建议在对应战场打开“配兵布阵”，每种角色做一个独立方案：

| 对应战场 | 建议新编号（若已有则换名） | 建议本批人数 |
|---|---|---:|
| 蟹怪围攻 | `V06Manual_Crab_A` | 90 |
| 绿皮小怪 | `V06Manual_Enemy_A` | 65 |
| 骷髅头军团 | `V06Manual_Skull_A` | 85 |

方案名称可以中文；编号和名称是两个字段。

- [ ] 减少本批人数，保持对面原配置；只改本局，不改官方资源或全局设置。
- [ ] 如愿意测试本局属性，把 HP 改成一个容易记住的合法值，并记录；不要强行使用表中默认值覆盖自己的全局配置。
- [ ] 使用新编号另存方案，应用并实际开战，确认人数 / 本局数值确实生效。
- [ ] 完全退出游戏，而不是仅返回菜单。
- [ ] 重新用同一个 `Start-WarSandbox.cmd` 启动。
- [ ] **先进入该方案所属的同一战场，再打开本地方案库载入。** 跨战场直接载入被拒绝是现有契约，不算新故障。
- [ ] 核对角色、人数、本局属性和部署没有丢失；应用后实际开战并自然结算。
- [ ] 不点击覆盖，不要求人工计算文件哈希；原来的个人方案仍应可见且没有被替换。

时间有限时，可先完成蟹怪的整条闭环，再补另两场。未做的项保持未勾选，不写成通过。
