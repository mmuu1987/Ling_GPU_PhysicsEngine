# Ling GPU Physics Engine

Unity project for experimenting with large-scale GPU-driven character simulation.

## Focus

- GPU instancing and indirect rendering
- Vertex animation texture playback
- GPU spatial hashing and collision-style separation
- Painted flow-field navigation
- Stage 5 two-team combat state logic

## Unity Project

Open this folder with Unity Hub:

```text
Ling_GPU_PhysicsEngine
```

The main project files are under `Assets/`, `Packages/`, and `ProjectSettings/`.
